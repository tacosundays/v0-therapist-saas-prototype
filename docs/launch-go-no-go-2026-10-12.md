- [ ] Refund procedure is rehearsed or the owner has documented the exact Stripe procedure.
- [ ] Vendor register contains retained BAA/eligibility evidence for every vendor permitted to handle PHI; unsupported PHI paths are disabled.
- [ ] Customer BAA acceptance path and retained signed copy have been tested.
- [ ] Privacy Policy, Terms, Security, BAA, Subprocessors, retention, acceptable use, cookies, accessibility, and AI/emergency notices have professional review appropriate to launch.
